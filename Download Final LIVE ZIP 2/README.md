# Shivtej Pratishthaan - Secure Web Application

Live demo React + Tailwind project with comprehensive **Ethical Hacking** security implementation.

## 🔒 Security Features

This application demonstrates industry-standard web security practices and ethical hacking techniques:

- **🛡️ XSS Protection** - Input sanitization with DOMPurify
- **🔐 Content Security Policy** - Prevents injection attacks  
- **🔗 URL Validation** - Protects against malicious redirects
- **📋 Security Headers** - X-Frame-Options, X-Content-Type-Options, etc.
- **🚫 CSRF Protection** - Safe form handling
- **⚡ Real-time Security Demo** - Interactive vulnerability testing

## 🚀 Quick Start

```bash
npm install
npm start
```

## 🔧 Security Scripts

```bash
# Run security audit
npm run security-audit

# Fix security vulnerabilities
npm run security-fix

# Comprehensive security check
npm run security-check
```
